# pydolbec.com

Personal site of Pierre-Yann Dolbec. Static, bilingual (EN/FR), served by GitHub Pages.

- Content: `_build/content.py`
- Templates and generator: `_build/build.py`
- Styles: `assets/css/site.css`

Rebuild after any change: `python3 _build/build.py`, then commit the generated folders.
